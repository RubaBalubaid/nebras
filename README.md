    <h1>Nebras</h1>
    <div class="justified">
        <p>
            The idea of Nebras application is a fun and educational game for kids. It aims
            to increase kids’ knowledge about several interesting topics. It contains
            3 categories (Math, Geography, and Religion). Each category will have a
            different question, and each question is considered a level. When the
            user wins the first level, level 2 will automatically be accessible, and more
            points will be added to the user’s record. The user’s progress is saved
            along with their account in the game’s database.
        </p>

        <h2>Tools</h2>
        <p>
            <b>Programming Language:</b> Java, JavaFx <br>
            <b>Framework:</b> Hibernate <br>
            <b>Database:</b> MySQL <br>
        </p>
